## 2. Công nghệ sử dụng (Tech Stack)
================================================================================
### 2.1 Frontend
- HTML5 (Semantic), CSS3
- Bootstrap 4.1.1 (Responsive Grid, Modal, Tab, Dropdown)
- Google Fonts: Open Sans (body), Raleway (banners)
- Icon Libraries: Font Awesome 5, Ionicons 4.2.0
- Animate.css (hiệu ứng CSS animation)

### 2.2 JavaScript & Plugins
- jQuery 3.3.1 (core DOM manipulation)
- Owl Carousel 2.3.4 (product sliders, main slider, brand slider)
- ElevateZoom (zoom ảnh sản phẩm trên trang chi tiết & quick-view modal)
- NProgress (thanh loading tiến trình)
- jQuery UI Range Slider (lọc giá sản phẩm)
- jQuery SlimScroll 1.3.8 (cuộn mượt trong sidebar filter)
- jQuery ScrollUp (nút cuộn lên đầu trang)
- Popper.js 1.14.3 (hỗ trợ Bootstrap dropdown/tooltip)
- Modernizr (phát hiện tính năng trình duyệt)
- Custom Plugins tự viết:
  + jquery.custom-megamenu.js (mega menu đa cấp)
  + jquery.custom-countdown.js (đếm ngược deal)
  + jquery.resize-select.js (resize select box danh mục tìm kiếm)

### 2.3 Quản lý giỏ hàng & Wishlist
- JavaScript thuần (Vanilla JS, IIFE pattern) + LocalStorage
- File xử lý chính: js/cart.js (880 dòng)
- localStorage key "cart": Mảng đối tượng { id, name, price, image, quantity }
- localStorage key "wishlist": Mảng đối tượng { id, name, price, image }
- Tự động normalize dữ liệu cũ (qty -> quantity)
- Dọn dẹp key cũ: shoppingCart, cartItems, groceryCart

### 2.4 Build Tools & Automation
- Webpack 4.12.2 (Thư mục html_webpack/)
  + Babel (ES6+ -> ES5 transpile)
  + SCSS -> CSS compile (node-sass, sass-loader)
  + MiniCssExtractPlugin (tách CSS từ JS)
  + HtmlWebpackPlugin (tạo 25+ file HTML từ template)
  + UglifyJsPlugin (minify JS cho production)
  + underscore-template-loader (HTML template partials)
  + file-loader (xử lý hình ảnh, fonts)
- PowerShell Scripts tự động hoá:
  + scripts/update_product_pages.ps1 (cập nhật hàng loạt trang sản phẩm)
  + fix_duplicate.ps1 (xóa section bị duplicate trong index.html)

### 2.5 Version Control
- Git (.gitignore: .idea, .vscode, node_modules/, /shelf/, /workspace.xml)

### 4.2 Luồng tải trang (Page Load Flow)
1. Browser tải HTML -> <head> loads CSS (bootstrap -> fontawesome -> ionicons -> animate -> owl -> range-slider -> utility -> bundle.css -> custom-modals.css)
2. <body> render DOM -> Footer trước </body> loads JS theo thứ tự:
   a. js/vendor/modernizr-custom.min.js (feature detection)
   b. js/nprogress.min.js (loading bar)
   c. js/jquery.min.js (jQuery core)
   d. js/bootstrap.min.js (Bootstrap components)
   e. js/popper.min.js (dropdown positioning)
   f. js/jquery.scrollUp.min.js (scroll to top)
   g. js/jquery.elevatezoom.min.js (image zoom)
   h. js/jquery-ui.range-slider.min.js (price filter)
   i. js/jquery.slimscroll.min.js (slim scrollbar)
   j. js/jquery.resize-select.min.js (select resizer)
   k. js/jquery.custom-megamenu.min.js (mega menu)
   l. js/jquery.custom-countdown.min.js (countdown timer)
   m. js/owl.carousel.min.js (carousels)
   n. js/app.js (application logic)
   o. js/cart.js (cart/wishlist logic)
   p. js/vmenu-sync.js (trên một số trang)
   q. js/search-results.js (chỉ trên trang search results)
3. jQuery document.ready fires -> app.js khởi tạo:
   - NProgress config
   - ScrollUp plugin
   - ElevateZoom cho product detail
   - ResizeSelect cho search category
   - MegaMenu plugin
   - CountDown timer
   - Responsive search form
   - Mini cart trigger
   - VMenu toggle
   - Quantity buttons (+/-)
   - Search form handler
   - Price range slider
   - Grid/List view toggle
   - SlimScroll for filters
4. cart.js IIFE tự khởi chạy:
   - clearOldCart() -> dọn key cũ
   - normalizeCartInStorage() -> convert format cũ
   - enrichProductCards() -> gán data-* attributes vào .item cards
   - initAddToCartButtons() -> event delegation cho .item-addCart
   - initCartPageActions() -> +/- quantity, remove
   - initCheckoutAction() -> form submit handler
   - initPackSizeSelection() -> #pack-size dropdown
   - initWishlistButtons() -> .item-addwishlist / .wishlist-btn
   - updateAllUI() -> cập nhật tất cả UI (count, mini-cart, cart page, checkout, wishlist)

Chi tiết luồng:
1. DUYỆT SẢN PHẨM: User xem sản phẩm trên index.html / shop-*.html
2. XEM NHANH: Click "Quick Look" -> Bootstrap Modal hiện với ảnh zoom, giá, nút +/-, Add to Cart
3. XEM CHI TIẾT: Click vào sản phẩm -> product-*.html với ElevateZoom, rating, reviews tab
4. THÊM VÀO GIỎ: Click .item-addCart -> cart.js#addToCart():
   - Lấy product info từ data-* attributes hoặc DOM parsing
   - Nếu đã có trong cart -> tăng quantity
   - Nếu chưa có -> push vào array
   - saveCart() -> localStorage.setItem('cart', JSON.stringify(...))
   - updateAllUI() -> cập nhật badge count, mini-cart, cart page
   - Visual feedback: nút chuyển "Added ✔" trong 1 giây
5. XEM GIỎ HÀNG: cart.html (body class="cart-page"):
   - renderCartPage() tạo bảng từ localStorage
   - +/- quantity buttons -> updateQuantity()
   - Remove button -> removeFromCart()

   - Submit -> validate inputs -> hiển thị QR Code + thông báo "ĐẶT HÀNG THÀNH CÔNG!"

### 4.4 Luồng tìm kiếm sản phẩm (Search Flow)
1. User nhập keyword vào search box + chọn category (optional)
2. app.js#handleSearchForm() intercept form submit
3. Redirect đến: shop-v6-search-results.html?q={keyword}&cat={category}
4. search-results.js init:
   - Parse URL params (q, cat)
   - Lọc .product-item theo keyword (title, breadcrumb)
   - Lọc theo category
   - Hiển thị số kết quả
5. Client-side filtering bổ sung:
   - Price range slider (jQuery UI)
   - Facet checkboxes: rice type (data-filter-rice), use case (data-filter-use)
   - Pagination (pageSize từ #show-records select)
6. Responsive search: nút #responsive-search trên mobile -> fadeIn search form

### 4.5 Luồng Wishlist
1. Click .item-addwishlist hoặc .wishlist-btn trên product card

3. Visual feedback: icon heart chuyển đỏ 1 giây
4. Wishlist badge (.wishlist-counter, .fixed-item-counter) cập nhật
5. Trang wishlist.html (body class="wishlist-page"):
   - renderWishlistPage() tạo bảng từ wishlist data
   - Nút "Add to Cart" từ wishlist -> addToCart()
   - Nút "Remove" -> removeFromWishlist()

### 4.6 Luồng Quick-View Modal
1. Click nút "Quick Look" trên product card
2. Trigger Bootstrap modal (#quick-view-{product-id})
3. Modal hiển thị: ảnh + zoom (ElevateZoom), tên, mô tả, giá, benefits list

- html_webpack/src/*.html: Source templates (có includes, partials)

## 9. Đánh giá & Ghi chú bảo trì
================================================================================

### 9.1 Ưu điểm
- Giao diện chuyên nghiệp, đầy đủ tính năng e-commerce cơ bản
- Responsive tốt (Bootstrap 4 grid)
- Hệ thống danh mục sản phẩm phong phú với mega menu đa cấp
- Quick-view modal cho mỗi sản phẩm (30+ modals)
- Cart/Wishlist hoạt động đầy đủ (CRUD) với LocalStorage
- SEO tốt: mỗi sản phẩm có trang riêng
- 8 color theme variants sẵn có
- Nhiều plugin UI (carousel, zoom, countdown, price slider)
- Blog system với 8 bài viết chi tiết

### 9.2 Điểm cần lưu ý
- **File lớn**: index.html = 6408 dòng (~446KB) - chứa nhiều section + 30+ modals
- **Trùng lặp code**: Header/Footer/Menu lặp lại trong mỗi file HTML
  -> Giải pháp: vmenu-sync.js đồng bộ menu, nhưng header/footer vẫn manual
- **Không có backend**: Tất cả logic phía client (LocalStorage), không lưu trữ server
- **Checkout đơn giản**: Form validation basic, hiển thị QR code (không kết nối payment gateway thật)
- **Mixed encoding**: Một số text Tiếng Việt bị garbled trong cart.js (UTF-8 encoding issue)
- **CSS lớn**: custom-modals.css = 119KB (mỗi modal có CSS riêng)

### 9.3 Key files cần chú ý khi sửa đổi
| File                | Vai trò                                     | Lưu ý                                    |
|---------------------|---------------------------------------------|-------------------------------------------|
| index.html          | Trang chủ, chứa 30+ Quick-View modals       | Rất lớn (446KB), cẩn thận khi edit       |
| js/cart.js          | Toàn bộ logic Cart + Wishlist + Checkout     | IIFE pattern, event delegation            |
| js/app.js           | Logic chung: sliders, search, UI interactions| 5 IIFE modules                            |
| js/vmenu-sync.js    | Đồng bộ menu danh mục trên mọi trang        | Sửa ở đây = sửa menu toàn site           |
| js/search-results.js| Client-side filtering & pagination           | Chỉ chạy trên shop-v6-search-results.html|
| css/bundle.css      | Theme CSS chính                              | ~96KB, controls brand colors              |
| css/custom-modals.css| Styles cho tất cả quick-view modals         | ~119KB, mỗi modal có styles riêng        |
| MODAL_CREATION_GUIDE.txt | Hướng dẫn tạo Quick-View modal mới      | 3 bước: CSS -> HTML -> JS                |

### 9.4 Quy trình bảo trì
1. **Thêm sản phẩm mới:**
   - Tạo product-{name}.html (copy từ template product có sẵn)
   - Thêm ảnh vào images/product/
   - Thêm Quick-View modal vào index.html (theo MODAL_CREATION_GUIDE.txt)
   - Thêm CSS modal vào css/custom-modals.css
   - Cập nhật menu trong js/vmenu-sync.js
   - Cập nhật trang danh mục (shop-*.html) nếu cần

2. **Sửa Header/Footer/Menu chung:**
   - Sửa js/vmenu-sync.js (cho menu danh mục)
   - Với Header/Footer: phải sửa thủ công từng file HTML
   - Hoặc dùng scripts/update_product_pages.ps1 cho batch update
   - Hoặc dùng Webpack (html_webpack) cho template-based update

3. **Thay đổi theme màu:**
   - Đổi link CSS từ bundle.css sang bundle.{color}.css trong <head>
   - 8 màu có sẵn: black, blue, green, green-munsell, orange, pink, purple, skyblue

4. **Build Webpack (nếu cần):**
   - cd html_webpack
   - npm install
   - npm run dev (development) / npm run build (production)
   - CẢNH BÁO: Output sẽ ghi vào html_webpack/dist, KHÔNG ĐÈ file root!
   - Cần merge manual nếu muốn dùng output
