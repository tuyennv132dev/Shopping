4. File JS quan trong
================================================================================

js/app.js
- Khoi tao plugin: NProgress, ScrollUp, ElevateZoom, ResizeSelect, MegaMenuDropDowns, CountDown.
- Xu ly UI chung: mini cart panel, search responsive, v-menu toggle, backdrop, quantity +/-.
- Xu ly search form: redirect ve shop-v6-search-results.html?q=...&cat=...
- Khoi tao carousel: main slider, product slider, category slider, brand slider.
- Mot so logic rieng cho contact/product/shop page.

js/cart.js
- Quan ly cart bang localStorage key "cart".
- Quan ly wishlist bang localStorage key "wishlist".
- Chuan hoa du lieu cart cu: qty -> quantity.
- Don key cu: shoppingCart, cartItems, groceryCart.
- Render mini cart, cart page, checkout page, wishlist page.
- Xu ly Add to Cart, Remove, Update Quantity, Add to Wishlist.
- Checkout hien modal QR/thong bao thanh cong, khong goi payment gateway that.

js/google-translate.js
- Dang duoc nhung tren tat ca 78 file HTML root.
- Source content la tieng Anh; VIE duoc dich bang Google Translate.
- LocalStorage key moi: htr_lang.
- Tu dong don key cu: gt_lang, site_lang, language.
- ENG: xoa trang thai Google Translate va reload ve ban goc tieng Anh.
- VIE: set cookie googtrans=/en/vi, load Google Translate va ep chon vi.
- Dropdown ngon ngu duoc gan data-htr-lang va notranslate de Google khong lam hong nut chon ngon ngu.
- Nhan chinh cua dropdown doi theo trang thai hien tai: ENG hoac VIE.

js/vmenu-sync.js
- Dong bo v-menu danh muc cho cac trang co .v-menu .v-list.
- Dang duoc nhung tren 34 file HTML.
- Thay innerHTML cua menu bang menu canonical.
- Nen sua danh muc chinh o day neu trang co dung v-menu-sync.

js/search-results.js
- Dang duoc nhung tren 12 file HTML.
- Xu ly loc client-side theo gia, loai gao, use case.
- Dong bo jQuery UI price slider voi input hidden.
- Render pagination va thay doi page size.

js/product-detail-renderer.js
- Renderer dung chung cho 19 trang product moi cua nhom beans/baby/seeds.
- Chon data theo ten file hien tai, vi du product-black-beans.html.
- Render title, breadcrumb, anh, gia, mo ta, benefit, usage tips va data-product-* cho cart.js.
- Giu moi san pham co URL rieng nhung tranh copy 19 trang HTML lon.

6. Luong nghiep vu chinh
================================================================================

6.1 Luong them vao gio hang
1. User click .item-addCart.
2. cart.js tim product tu data-product-* tren .item, hoac fallback tu title/price/image.
3. Du lieu luu vao localStorage "cart".
4. UI duoc cap nhat: counter, total, mini cart.
5. Cart page va checkout page render lai tu localStorage.

6.2 Luong wishlist
1. User click .item-addwishlist hoac .wishlist-btn.
2. cart.js luu vao localStorage "wishlist".
3. Counter wishlist cap nhat.
4. wishlist.html render danh sach tu localStorage.

6.3 Luong checkout
1. checkout.html render order summary tu cart.
2. User nhap thong tin.
3. Submit form chi validate co ban tren client.
4. Hien modal QR/thong bao dat hang thanh cong.
5. Khong co server, khong co thanh toan that, khong luu don hang len database.

6.4 Luong search
1. User submit search form tren header.
2. app.js redirect ve shop-v6-search-results.html voi query q/cat.
3. app.js va search-results.js loc san pham client-side.
4. search-results.js xu ly them facet, price slider, pagination.

6.5 Luong doi ngon ngu
1. User chon ENG/VIE trong header.
2. google-translate.js bat click dua tren data-htr-lang, khong phu thuoc text da bi dich.
3. VIE: luu htr_lang=vi, set googtrans, reload/load Google Translate.
4. ENG: luu htr_lang=en, xoa cookie/storage Google Translate, reload ve source tieng Anh.
5. Dropdown hien dung trang thai hien tai: ENG hoac VIE.

9. Ket qua audit URL noi bo
================================================================================

Da audit cac attribute trong 78 file HTML:
- href
- src
- action
- data-image
- data-zoom-image

Ket qua sau khi sua:
- Khong con URL noi bo nao trong cac attribute tren tro toi file khong ton tai.
- Khong con link home.html bi chet; da doi ve index.html.
- Khong con asset product@1x.jpg bi thieu; da doi ve product@2x.jpg.
- Cac anh banner/blog/product bi thieu da duoc map ve asset dang co.
- Cac link san pham beans/baby/seeds da duoc tro ve trang product detail rieng.

Nhung diem can luu y sau audit:
- 19 trang product moi dung chung js/product-detail-renderer.js de render noi dung theo URL.
- Mot so anh van la fallback/generic asset vi chua co file anh rieng cho tung san pham.
- Neu can SEO toi da khong phu thuoc JS render, co the static-hoa noi dung 19 trang nay ve HTML rieng.

12. Quy trinh khuyen nghi khi sua tiep
================================================================================

Khi sua header:
1. Tim tat ca bien the trong root HTML.
2. Sua bang batch co regex he hep.
3. Audit lai bang rg voi keyword cu.
4. Chay lai audit URL noi bo.

Khi them san pham moi:
1. Tao product-{slug}.html.
2. Them anh vao images/product/.
3. Cap nhat product card trong category/home neu can.
4. Cap nhat quick-view modal neu san pham xuat hien o index/home.
5. Them data-product-* day du cho cart.js.
6. Audit href/src/data-image/data-zoom-image sau khi them.

Khi sua menu danh muc:
1. Neu trang dung vmenu-sync.js, sua js/vmenu-sync.js.
2. Neu trang co menu hard-code rieng, can sua root HTML tuong ung.
3. Kiem tra lai mobile/desktop vi MegaMenuDropDowns phu thuoc markup.

Khi sua ngon ngu:
1. Sua js/google-translate.js.
2. Khong de Google dich nut ENG/VIE; giu notranslate.
3. Kiem tra ca chieu ENG -> VIE va VIE -> ENG.
4. Kiem tra localStorage htr_lang va cookie googtrans.

Khi audit URL:
1. Quet href/src/action/data-image/data-zoom-image trong tat ca HTML.
2. Bo qua http, https, mailto, tel, javascript, data, anchor.
3. So voi file thuc te tren disk.
4. Sua link chet ve file dung hoac tao file thieu.
