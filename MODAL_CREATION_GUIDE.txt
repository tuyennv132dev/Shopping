## BUOC 3: CAP NHAT LINK VA JAVASCRIPT (index.html)

1. **Link Quick Look:** Tim san pham trong danh sach va doi `href="#quick-view"` thanh `href="#quick-view-[product-id]"`.
2. **Khoi tao Zoom:** Them code vao phan `<script>` cuoi file:

```javascript
$('#zoom-pro-quick-view-[product-id]').elevateZoom({
    gallery: 'gallery-quick-view-[product-id]',
    galleryActiveClass: 'active',
    zoomEnabled: false,
});
```
